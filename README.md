# Dotquad Homebrew tap

Homebrew formulae for Dotquad's command-line tools.

```sh
brew install dotquad/tap/dotquad
```

| Formula   | What it is                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------- |
| `dotquad` | IP lookup, DNS, WHOIS and domain checks from the terminal ([source](https://github.com/dotquad/cli)) |

The formulae are updated by each project's release workflow. Report problems in the project's own repo.
